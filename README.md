# 📊 Marketing Campaign Insights Analysis | Power BI

 **📌 Project Overview**

The Marketing Campaign Insights Analysis Dashboard is an interactive business intelligence project developed using Microsoft Power BI.

This project focuses on analyzing marketing campaign performance, audience segments, marketing expenditure, conversions, revenue, and return on investment (ROI) to generate meaningful business insights.

The dashboard helps understand campaign effectiveness and evaluate marketing channel performance through data visualization and interactive reporting.

**Project Objectives**

- Analyze overall marketing campaign performance.
- Evaluate marketing expenditure and generated revenue.
- Identify high-performing marketing channels.
- Analyze audience segments and demographic patterns.
- Track clicks, impressions, and conversions.
- Measure campaign effectiveness using CTR and conversion rate.
- Evaluate campaign profitability and ROI.
- Support data-driven marketing decisions.

**Tools & Technologies**

**🚀 How to Run the Project**

1. Download or clone the GitHub repository.
2. Open the `.pbix` file using Microsoft Power BI Desktop.
3. Update the Excel source file path if required.
4. Refresh the dataset.
5. Explore the interactive marketing campaign dashboard.
